# Кудри, учёт

Простая личная база клиентов для мастера: визиты, услуги, оплата и заметки. Работает без сервера — записи сохраняются в браузере на текущем устройстве.

## GitHub Pages

1. В настройках репозитория откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/(root)`, затем сохраните.

Через несколько минут страница будет доступна по адресу `https://daryasayuri.github.io/curly/`.

Важно: периодически нажимайте «Скачать резервную копию». Так записи можно перенести на другое устройство или восстановить после очистки браузера.
